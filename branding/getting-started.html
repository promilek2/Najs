Getting started with Najs

Najs is ready to use. The application menu contains your browser, files, settings, software center, and every application selected during installation.

Common tasks

  • Install applications: open the software center from Najs Welcome.
  • System settings: change display, sound, network, users, and appearance.
  • Files: open your home folder from Najs Welcome or the application menu.
  • Flatpak: Flathub is configured automatically when the network is available.

System diagnostics

Run najs doctor in a terminal to check the core system. Run najs info to see release and generation information.

Najs Welcome remains available in the application menu even when automatic startup is disabled.
